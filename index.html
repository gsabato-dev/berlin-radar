Set up saving (once per device)
  1. In Safari, open GitHub → new fine-grained token.
  2. Name it “Berlin Radar”, expiration up to 1 year. Repository access: only the settings repo.
  3. Permissions: Contents → Read and write, Actions → Read and write. Generate and copy it.
  4. Paste it here. It is kept only on this device.

These open GitHub in Safari. Sign in there as gsabato-dev once; otherwise GitHub shows “Page not found”.
